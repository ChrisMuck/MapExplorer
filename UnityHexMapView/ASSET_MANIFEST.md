# Asset Manifest

This Unity prototype currently uses no external art assets.

All visuals are original procedural placeholders generated in code:

- Hex terrain meshes
- Procedural material colors
- Procedural noise textures
- Irregular terrain brush meshes
- River, road and border ribbon meshes
- Tree, forest, mountain, settlement and marker primitives
- Lighting and camera setup

If external assets are added later, list each asset here with:

- Source URL
- License
- Author or attribution text, if required
- Files imported
- In-project usage
